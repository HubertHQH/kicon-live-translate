KiCon Asia 2026 · 实时同传 — Windows 完整安装版
版本 1.0.0 / Windows x64

一、另一台电脑需要准备什么
推荐使用 Windows 11 或已更新的 Windows 10（64 位 Intel / AMD 电脑），预留至少 1 GB 磁盘空间。
安装包已包含 Electron、Chromium、Node.js、本地服务、控制台、投屏页面和桌面字幕组件。
无需安装 Node.js、npm、Python、浏览器插件或编译工具。安装过程不需要联网下载组件。
实时识别与翻译使用云端 Qwen 服务，需要互联网、有效 API Key 和账户余额。模型不在本地运行。
麦克风输入需要麦克风或 USB 声卡；采集电脑声音时不要求麦克风。

二、安装与首次启动
1. 复制 KiCon-Live-Translate-Setup-1.0.0-x64.exe 到新电脑。
2. 双击安装，按向导选择安装位置。默认按当前用户安装，无需管理员权限。
3. 双击桌面的“KiCon 实时同传”，或从开始菜单打开。
4. 在顶部“配置”页面填写自己的 API Key，检查 Base URL 和模型，点击“保存配置”。
   默认 Base URL：https://maas.qianwenaiapi.com/compatible-mode/v1
   默认模型：qwen3.8-livetranslate-flash-realtime（沿用当前项目的实际配置）。
   若账户已有其他模型权限，可在配置页修改。实时地址必须兼容本项目的 WebSocket 协议。
5. 返回工作台，先点击“预览演示字幕”检查字幕及投屏；演示不调用云端模型、不计费。
6. 停止演示后，选择音频来源，再开始同传。
安装包没有附带原电脑的 API Key 或历史字幕，避免随安装包泄漏。
本安装包未使用商业代码签名证书，Windows 可能显示“未知发布者”。

三、字幕窗口
“桌面字幕”：打开置顶的透明字幕窗口，拖动顶部移动，拖动右下角调整大小。
背景透明度 100% 表示完全透明，0% 表示实色；文字本身不会随背景一起消失。
“打开悬浮字幕”：浏览器画中画窗口；浏览器限制使其背景不能透出其他应用。
“打开投屏窗口”/“观众屏幕”：独立观众窗口，可拖到外接屏幕并全屏。
字号、语言、段落、主题、配色和透明度自动保存，桌面字幕位置及大小也会保存。
关闭字幕窗口不会停止同传。停止采集请点“停止同传”；关闭主控制台会退出安装版及其本地服务。
安装版不需要运行 start.cmd 或 start-overlay.cmd，也不依赖源码文件夹。

四、配置和数据在哪里
按 Alt 显示菜单 → KiCon 同传 → 打开本机数据文件夹。
也可以在资源管理器地址栏输入：%APPDATA%\KiConLiveTranslate
  config.env             模型、地址、API Key 及可选计价配置
  display.json           字号、语言、配色、透明度等
  desktop-window.json    桌面字幕位置和大小
  recordings\            历史字幕及用量记录，不包含麦克风原始录音
  其余文件               内置浏览器的缓存和窗口状态
安装在 Program Files 等目录时，配置仍写入上述用户目录。
API Key 保存在当前用户的本地配置文件中，请勿公开分享该文件。
正常升级安装保留用户数据；卸载也保留用户数据，便于重装恢复。彻底清除时请先备份，再手动删除上述目录。

五、迁移原电脑的个人设置（可选）
仅安装程序就能运行；如还需继承原有设置或记录，请关闭两边程序后迁移。
从当前源码版迁移到安装版：
  原项目 .local\display.json        → 新电脑数据目录 display.json
  原项目 .local\desktop-window.json → 新电脑数据目录 desktop-window.json
  原项目 recordings\              → 新电脑数据目录 recordings\（可选）
  原项目 .env                     → 新电脑数据目录 config.env（包含密钥，仅自行安全传输）
从安装版迁移到安装版：复制上面的 config.env、display.json、desktop-window.json 和 recordings 文件夹即可。
浏览器画中画的大小随浏览器站点数据保存，不建议复制整套 Chromium 缓存；迁移后可重新调整一次。
显示器布局不同时，桌面窗口会自动限制到可见范围。

六、常见问题
没有声音：先检查 Windows 设置 → 隐私与安全 → 麦克风，允许桌面应用访问；确认输入设备及系统输入电平。
电脑声音：选择电脑音频来源，开始同传后确认采集；此模式采集系统播放声音，也可能包含其他应用的声音。
不能连接模型：检查网络、Base URL、实时连接地址、密钥、账户权限和余额。界面显示“未计价”时请配置对应模型单价。
端口占用：安装版会选择可用端口并记住，不会误连已运行的源码服务。
希望使用外部 Chrome / Edge：程序运行时，数据目录 service-port.json 中的 port 是当前端口；访问 http://localhost:该端口。
安装版与源码版分别保存配置和会话；同一安装版控制台打开的桌面字幕与观众窗口会同步。
透明效果仍依赖 Windows 桌面合成和显卡驱动，远程桌面或部分录屏工具可能改变透明窗口的呈现。
