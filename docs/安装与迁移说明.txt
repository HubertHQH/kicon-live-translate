安装与使用 / 版本 1.0.1 / Windows x64 / 2026-10-25

一、准备条件
建议 Windows 11（64 位 Intel / AMD 电脑），预留至少 1 GB 空间。本机 Windows 11 已验证；Windows 10 x64、不同显卡和音频设备需在目标电脑试用。此交付物不适用于 macOS、Linux 或 Windows 32 位，未验证 Windows ARM。
安装器内置 Electron、Chromium、Node.js、本地服务、控制台、投屏及桌面字幕。无需 Node.js、npm、Python、开发工具或浏览器插件，安装本身无需联网下载组件。
真实识别和翻译使用云端 Qwen，需要网络、自己的 API Key、模型权限和可用额度。模型不在本地运行。
程序未代码签名，Windows 可能提示未知发布者。请确认发送者和文件校验值，不要关闭安全防护；企业电脑按单位安装流程处理。

二、安装与首次启动
1. 解压 KiCon-Live-Translate-1.0.1-Windows-x64.zip。
2. 运行 KiCon-Live-Translate-Setup-1.0.1-x64.exe，按向导安装，默认按当前用户安装。
3. 打开桌面或开始菜单“KiCon 实时同传”。
4. 顶部“配置”中填写自己的 API Key，核对默认配置并保存：
   Base URL：https://maas.qianwenaiapi.com/compatible-mode/v1
   模型 ID：qwen3.8-livetranslate-flash-realtime
   实时连接地址（高级选项）：wss://maas.qianwenaiapi.com/api-ws/v1/realtime
5. 返回工作台，点“预览演示字幕”检查窗口。演示不采集声音、不调用模型、不产生模型费用。
6. 点击“停止同传”结束演示，再设置真实输入。
默认模型为项目实际接入配置，不保证每个账号有权限。更换服务必须兼容 Qwen 实时 WebSocket 协议，普通聊天 API 不能直接替代。
保存只验证格式，不验证远端权限。已有 Key 不回显，留空表示保留；更换时填新值。运行中不能保存配置，新会话使用新配置。
安装包不含原电脑的 Key、个人设置或会议记录。安装版不需要 start.cmd、start-overlay.cmd 或源码。
按 Alt → KiCon 同传 → 使用说明 / 关于，可查看离线帮助和版本。

三、第一次同传：建议先试一分钟
1. 麦克风 / 调音台输入：选择正确设备，设备变更后点刷新。电脑声音：选择“电脑 / 浏览器共享音频”，安装版需确认采集提示，外部浏览器需勾选“共享音频”。
   系统声音可能包含无关应用和通知；屏幕画面不发送给模型或保存。
2. 中文演讲选“中文演讲 → English”，英文演讲选“English talk → 中文”，每种使用一个会话，原文直接使用识别增量，通常更早出字。
   中英交替选“中英交替 · 自动双向”，相同音频发送到两个会话，分别生成中、英文，两侧均等待目标流，用量增加。控制台另保存原文。
3. 字幕响应默认快速断句（0.3 秒静音），慢速或停顿多可选稳健断句（0.6 秒静音），下次开始生效。实际提速因语音和模型上下文而异，未验证出稳定的大幅改善。
4. 会议术语每行：中文 = English。新会话生效，模型不保证所有术语正确。
5. 点击“开始同传”，看到“正在同传”后讲话，确认电平变化、字幕出现。
6. 点击“停止同传”，等待末句完成后导出 TXT / SRT，再关闭程序。正常收尾有助保留末句。
暂停字幕、临时黑屏、关闭字幕窗口都不停止采集和计费。刷新或关闭采集控制台会结束采集。
网络或模型报错后不自动恢复采集，不补传断线期间音频；恢复后手动重新开始。

四、投屏、悬浮和桌面字幕
观众屏幕 / 打开投屏窗口：接到同一电脑的外接屏幕或投影仪，Windows 显示设置选扩展，把观众窗口拖过去后全屏（按钮或 F；浏览器也可 F11）。不是跨电脑远程投屏。
打开悬浮字幕：浏览器画中画，置顶，拖标题栏移动、边缘缩放。需要浏览器支持；背景不能透出其他应用。
桌面字幕：真正透明的置顶窗口，拖动顶部移动，拖动右下角缩放。需要背景透明请选择此项。
“悬浮窗配色与透明度”：中英文字色和背景色可分别设置。背景透明度 100% 全透明，0% 实色，文字本身不变淡；只影响悬浮 / 桌面字幕，不改变普通观众屏幕配色。
视觉透明不代表鼠标穿透，文字和操作区域可能拦截点击。远程桌面、驱动及录屏工具可能影响透明效果。
每种语言最多显示 1–5 行或随窗口高度，默认 2 行。长句超出时显示最新行，完整内容仍保留；“保留的字幕段落”独立控制历史段落。
语言、字号、行数、配色、透明度和桌面窗口位置尺寸自动保存，同一服务内同步。暂停和黑屏不跨重启恢复。安装版和源码版分别保存配置，勿同时开启两套采集。

五、Token、时长和费用
本次用量显示输入 / 输出 / 合计 token、时长、预估费用及平均每分钟费用。收到模型完整用量后更新，流式生成时可能暂未回报。
双向用量已合计，不再乘二；计时按实际经过时间计算，含连接和收尾。暂停字幕或黑屏仍计时。
费用按已知单价估算，内置价格为历史参考，不自动随平台更新；不扣套餐、赠送额度和折扣。“部分 / 未计价”代表尚有费用未计入，不代表免费，最终以服务商账单为准。
演示不调用付费模型；初次真实试用先运行一分钟，停止后检查用量。
计价可由维护者在 config.env 设置 QWEN_PRICE_INPUT_AUDIO、QWEN_PRICE_OUTPUT_TEXT、QWEN_PRICE_INPUT_TEXT 等人民币/百万 token 参数并重启。不确定的价格不要填 0。

六、数据、隐私和导出
按 Alt → KiCon 同传 → 打开本机数据文件夹；或在资源管理器输入：%APPDATA%\KiConLiveTranslate
  config.env             模型、地址、API Key、计价参数
  display.json           字号、语言、行数、配色、透明度等
  desktop-window.json    桌面窗口位置和大小
  recordings\            原文、译文修订、用量记录（JSONL）
  service-port.json      本地服务端口
  其他文件               内置浏览器站点存储和缓存
本机不存原始音频；同传时音频和术语发送至所配云服务，云端保留和处理由服务商决定。请在有权采集、处理会议内容的场合使用。
API Key 以配置文本存于本机，未用系统密钥库加密。会议记录可能敏感，不要把 config.env、.env、recordings 或整个用户目录随程序转发。
“字幕与会话记录 → 查看本地存档”可导出完整 TXT / 分语言 SRT，不受屏幕最近 2000 条限制。SRT 使用接收时间，剪辑前需校准；记录文件名使用 UTC。
卸载保留数据和密钥。彻底清除需先退出程序、备份所需内容，再自行删除上述用户目录。

七、升级和迁移
升级前停止同传并等末句，退出程序，备份必要数据，再运行新版安装器。升级不自动导入源码配置。
新电脑先安装并运行一次，然后关闭两边程序，复制必要文件至新电脑数据目录：
  安装版 → 安装版：display.json、desktop-window.json、recordings\。
  源码版 → 安装版：项目 .local\display.json → display.json；.local\desktop-window.json → desktop-window.json；recordings\ → recordings\。
Key 建议在新电脑配置页重新填写。确需迁移自己的账号时才安全传输 config.env；源码 .env 对应安装版 config.env。使用自己账号的第三方不需要你的密钥。
发言方向、术语、字幕响应、浏览器悬浮尺寸在当前控制台站点存储，上述文件迁移不包含它们；迁移前复制术语文字，迁移后重设。不要复制整套 Chromium 缓存。
清除站点数据、更换浏览器或端口改变，也可能重置站点存储设置；桌面位置会根据新显示器布局调整。

八、常见问题
不能安装 / 启动：确认已解压并使用 x64 系统，查看错误和防护提示；企业电脑联系 IT，不关闭安全防护。
无麦克风声音：检查 Windows 隐私与安全 → 麦克风 → 允许桌面应用访问；检查设备、调音台输出和输入电平。
无电脑声音：确认音频在播放，安装版确认采集，浏览器勾选共享音频；部分浏览器或来源不支持。
无法连接模型：检查网络、Key、模型权限、余额及地址；保存配置不代表连接验证成功。
字幕不更新：检查暂停、黑屏、电平和连接状态；断线后恢复网络再手动开始。
背景实色：使用桌面字幕并将透明度设为 100%，浏览器悬浮不能透明。
字幕长：设置每种语言行数，调整字号或窗口尺寸，超出保留最新行。
字幕慢：试快速断句；固定语言用单向，让原文更早显示。模型仍可能等待上下文，不能保证逐字同步或官网视频效果。
中英切换漏句：部分连续切换测试出现空结果 / 漏句，尚未解决。重要会议先彩排，固定语言优先单向；未完成连续数小时、会场噪声验收。
端口占用：安装版自动选择可用端口，不会误连源码版服务。
外部 Chrome / Edge：保持安装版运行，查看 service-port.json 的 port，访问 http://localhost:对应端口。不要开放公网监听。
记录找不到：安装版数据目录与源码目录不同，可用程序菜单确认。

正式使用前用实际演讲人、术语、调音台线路、网络及显示器彩排，关闭无关音源，会后先停止再退出。
反馈给提供安装包的人：版本、Windows 版本、音频来源、发言方向、字幕响应、错误文字和复现步骤。截图不得包含密钥，会议片段先脱敏。本交付物不承诺官方厂商支持。

九、校验文件
ZIP 旁 .sha256.txt 用于校验整个压缩包；解压后的 SHA256SUMS.txt 用于核对安装器和说明。
PowerShell 可运行：Get-FileHash -Algorithm SHA256 -LiteralPath "压缩包完整路径"
将结果与可信发送者给出的值比较。校验能发现变化，但不等同于代码签名，也不能单独证明身份；不要执行来源不明的修复脚本。
